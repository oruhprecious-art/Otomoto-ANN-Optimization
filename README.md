# Otomoto ANN Optimization Project

## Purpose
This project compares three optimizers for a feed-forward artificial neural network using the supplied `teleconnect.csv` customer churn dataset. The target is **Churn** (Yes/No), so the model supports **churn-risk segmentation** rather than unsupervised customer segmentation.

## Files
- `ann_optimizer_comparison.py` — preprocessing, training, evaluation, plots, and model export.
- `data/teleconnect.csv` — assignment dataset supplied with the task.
- `results/optimizer_comparison.csv` — sample results from the first run.
- `figures/` — comparison charts and confusion matrices (confusion matrices are created when the script is run).
- `models/best_ann_model.joblib` — best-F1 model generated by running the script; the report's metrics are from the run completed for this project.
- `report.docx` — project report.

## Run in PyCharm or a terminal
1. Use Python 3.10+.
2. Install dependencies: `python -m pip install -r requirements.txt`
3. Run: `python ann_optimizer_comparison.py`

## Methods
- 80/20 stratified train/test split with fixed random seed 42.
- Excludes `customerID` because it is an identifier, not a meaningful predictor.
- Converts `TotalCharges` to numeric and imputes missing values.
- Standardizes numerical inputs and one-hot encodes categorical inputs.
- Compares Adam, stochastic gradient descent (SGD), and L-BFGS with the same `(64, 32)` hidden-layer structure.

## Important interpretation
The highest test F1-score in the included run was produced by SGD (about 0.582). Adam achieved the strongest ROC-AUC (about 0.839). If the business priority is to identify as many customers likely to churn as possible, consider tuning the decision threshold using a validation set and comparing recall, precision, and campaign capacity. Do not treat a model score as proof of marketing uplift; validate with a controlled campaign experiment.

## Reproducibility and limitations
Results can vary with library versions and hardware. This is a compact assignment baseline, not a production deployment. Use a separate validation set for model selection and preserve the test set for one final evaluation. The dataset contains customer-level information, so access and retention should follow applicable privacy rules.
